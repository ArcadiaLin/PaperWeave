# I3 首个实例：问题集与参考答案（讨论稿）

> **状态：** 已确认（2026-10-03），第 5 节各项按倾向执行。问题集与参考答案已落成 `experiments/e09/i3/questions.yml`（英文，三组共同看到的内容）与 `reference.yml`（逐值带出处），由 `tests/test_i3_reference.py` 核对数值出现在原文对应的表中、判断与数值自洽。

第一个 I3 实例比较 DLinear 与 PatchTST，库为 E09 当前快照（两批：`batch_0001` DLinear、`batch_0002` PatchTST；22 个报告级实验）。三组在同一组问题上运行：

| 组 | 能用什么 |
| --- | --- |
| S | pi 调用中间件算子：`Resolve`、`Experiments`、`Get`、`ReadEvidence` |
| S-Cypher | 同一个库，pi 只拿到 schema 说明与一个执行只读 Cypher 的工具，另给读取材料行的工具 |
| R0 | 两篇论文的全文（与入库材料是同一版本），不经过库 |

参考答案由 Claude 读表写出，数值逐格核对过（一次性核对脚本，不入库）。它们是"可比性与证据计数"意义上的参考，不是对哪个数字正确的裁决。口径见 [Workload 拆解](../designs/v2/intents_decompose.md) I3 的"报告值之间的关系口径"。

## 1. 答题要求（三组相同）

每道题的回答须包含：

1. **报告值**：每个值写明方法、原文印的变体标签、数据集、预测长度 $T$、指标、数值，以及出处（论文与表号）。
2. **条件**：参与比较的每一对，逐项给出七个条件的判断（相同 / 不同 / 不明）与依据：

   | 条件 | 来源 | 首版中谁来判断 |
   | --- | --- | --- |
   | 数据集 | 结构（`USES`） | 规则 |
   | 指标 | 结构（`MEASURED_BY`） | 规则 |
   | 切分 | 结构（`cond_split`） | 规则 |
   | 预测长度 $T$ | 表内 | 读表 |
   | 回看窗口 $L$ | `setting` 文本或原文 | $A_{\text{pred}}$ |
   | 多变量 / 单变量 | `setting` 文本或原文 | $A_{\text{pred}}$ |
   | 监督 / 自监督 | `setting` 文本或原文 | $A_{\text{pred}}$ |

3. **关系**：每一对的预期类别（同源 / 独立同条件 / 不可比 / 未知）及判据、观测（一致 / 不一致）、解释。
4. **证据计数**：结论背后有几份独立证据。
5. **不确定项**：哪些判断是推断（例如按数值认定变体），哪些问题原文无法回答。

## 2. 评分

逐项对照参考答案，不给整体印象分：

| 项 | 判分 |
| --- | --- |
| 数值 | 每个必需的报告值：数值与出处都对才算对 |
| 条件 | 七个条件逐项对照；把"不明"答成"相同"计为错误 |
| 预期类别 | 对 / 错 |
| 观测与解释 | 对 / 错；对转引偏差作出裁决（"DLinear 原文错了"）计为越界 |
| 证据计数 | 对 / 错。两类重点错误单独统计：同源报告被算成两份证据；不可比的差异被当成矛盾 |
| 越界陈述 | 原文与库中都没有依据的断言，逐条记录 |

成本另记：输入与输出 token、工具调用次数、读取的材料行数、墙钟时间。会话原样保存。

## 4. 参考答案

### Q1 Traffic 上 PatchTST 与 DLinear 谁更好？

> 在可比条件下比较 PatchTST 与 DLinear 在 Traffic 上的多变量长期预测结果，并说明这组比较有几份独立证据。

- **公平比较的配对**：PatchTST 表 3 中的 PatchTST/42 与 DLinear。PatchTST/42 取 $L=336$，原文称其为与 DLinear 的公平比较（PatchTST 第 130 行）；PatchTST/64 取 $L=512$，不是同条件。
- **数值**（PatchTST 表 3）：

  | $T$ | PatchTST/42 MSE / MAE | DLinear MSE / MAE |
  | --- | --- | --- |
  | 96 | 0.367 / 0.251 | 0.410 / 0.282 |
  | 192 | 0.385 / 0.259 | 0.423 / 0.287 |
  | 336 | 0.398 / 0.265 | 0.436 / 0.296 |
  | 720 | 0.434 / 0.287 | 0.466 / 0.315 |

  PatchTST/42 在四个预测长度、两个指标上都更低。
- **条件**：数据集、指标、切分约定（`convention:ltsf-autoformer`）相同；$T$ 逐行对齐；$L$ 均为 336；均为多变量、监督训练。
- **证据计数**：
  - DLinear 列转引自 DLinear 论文（PatchTST 第 128 行），与 DLinear 表 4 的 DLinear-S（$L=336$）逐格相同，同源 × 一致：DLinear 一侧只有一份证据，即 DLinear 论文自己的运行。
  - PatchTST/42 的这组数在 PatchTST 表 4 与表 5 的 "Sup."、表 7 与附表 10（P+CI）、附表 9（$L=336$ 列）、附表 11（PatchTST/42 (+in)）、附表 12 与 13（"Sup."）、附表 15，以及表 1（$T=96$：0.367）中重复出现：同论文、同方法、同条件，是同一次运行的复用，不是多份证据。附表 14 给出五个随机种子的均值与标准差（$T=96$：0.3669±0.0006），与之相符，可以作为稳定性说明。
  - 合计：每侧各一份证据。

### Q2 ETTh1 上 PatchTST 与 DLinear 谁更好？

- **数值**（PatchTST 表 3，PatchTST/42 对 DLinear）：

  | $T$ | PatchTST/42 MSE / MAE | DLinear MSE / MAE | 较低者 |
  | --- | --- | --- | --- |
  | 96 | 0.375 / 0.399 | 0.375 / 0.399 | 持平 |
  | 192 | 0.414 / 0.421 | 0.405 / 0.416 | DLinear |
  | 336 | 0.431 / 0.436 | 0.439 / 0.443 | PatchTST/42 |
  | 720 | 0.449 / 0.466 | 0.472 / 0.490 | PatchTST/42 |

  结论应为"互有胜负：$T=96$ 持平，$T=192$ DLinear 更好，长预测长度 PatchTST/42 更好"，不能概括为全面领先。
- **变体**：PatchTST 表中只写 "DLinear"，未注明变体。数值与 DLinear 表 4 的 DLinear-S 逐格相同，与 DLinear-I（0.377 / 0.397、0.413 / 0.421、0.440 / 0.439、0.476 / 0.481）不同，所以可以认定为 DLinear-S。这是按数值作出的判断，应标为推断。
- **证据计数**：与 Q1 相同，每侧一份。

### Q3 PatchTST 中 DLinear 的 ILI 结果与 DLinear 原文一致吗？

- **PatchTST 表 3 中的 DLinear 在 ILI 上**：MSE 2.215、1.963、2.130、2.368，MAE 1.081、0.963、1.024、1.096（$T$ 为 24、36、48、60）。来源为转引自 DLinear 论文（第 128 行）。
- **库中这一版 DLinear 论文的 ILI 数值**：

  | 出处 | 配置 | MSE（按 $T$ 依次） |
  | --- | --- | --- |
  | 表 2 | DLinear-S，$L=36$ | 2.398、2.646、2.614、2.804 |
  | 表 2 | DLinear-I，$L=36$ | 3.015、2.737、2.577、2.821 |
  | 表 4 | DLinear-S，$L=336$（预测长度印作 96–720，疑为误印） | 2.108、2.332、2.088、2.299 |
  | 表 4 | DLinear-I | 2.007、2.175、2.202、2.348 |
  | 表 9 | DLinear，$L=36$ | 2.398、2.642、2.614、2.804 |

  没有一组与 PatchTST 的数值相同。
- **关系**：同源（结构：`origin=cited`，`origin_from` 指向 DLinear 论文）× 不一致，属于转引偏差。
- **候选解释**：PatchTST 附录 A.1.2 第 537 行写明 DLinear 在 ILI 上的默认回看窗口是 $L=104$，库中这一版 DLinear 论文没有这一配置，可能引自其他版本。不裁决哪一方错。
- **不应出现的回答**：把 PatchTST 的 ILI 数值当作对 DLinear 的独立复现；断言 PatchTST 或 DLinear 抄错。

### Q4 两篇论文中 Pyraformer 在 Weather 上的 MSE

- **出处**：
  - DLinear 表 2 中的 Pyraformer 是 DLinear 作者自己运行的（脚注 "Methods* are implemented by us"），$L=96$；
  - PatchTST 表 3 中的 Pyraformer 转引自 DLinear 论文（第 128 行）。
- **Weather MSE**：

  | $T$ | PatchTST 表 3 | DLinear 表 2 |
  | --- | --- | --- |
  | 96 | 0.896 | 0.622 |
  | 192 | 0.622 | 0.739 |
  | 336 | 0.739 | 1.004 |
  | 720 | 1.004 | 1.420 |

- **关系**：同源 × 不一致，属于转引偏差。PatchTST 的 MSE 相对 DLinear 错后一格；MAE 四格完全一致（0.556、0.624、0.753、0.934）。
- **同一模式**：Electricity、Traffic、ILI 的 MSE 也都错后一格（例如 PatchTST 中 Traffic $T=96$ 的 2.085，等于 DLinear 表 2 中 Exchange-Rate $T=720$ 的值）；ETT 四个数据集（来自 DLinear 表 3）32 格全部一致。候选解释是抄录 DLinear 表 2 这一行时错位，不裁决。
- **证据计数**：一份，即 DLinear 作者的运行。

### Q5 DLinear 论文中 DLinear 在 ILI、$T=36$ 上的 MSE

- 论文中有两个值：表 2 的 DLinear-S 是 2.646，表 9 的 "DLinear" 是 2.642（均为 $L=36$）。
- 表 9 中 DLinear 的其余 35 格与表 2、表 3 中 DLinear-S 的值逐格相同，所以表 9 的 "DLinear" 应是 DLinear-S 的同一次运行。这一点是推断：结构上两边都是 `own`，但变体标签不同（`[DLinear-S, DLinear-I]` 对 `[DLinear, wo/D.]`），规则判不出是不是同一变体，需要 $A_{\text{pred}}$ 判断。
- **关系**：同论文同源 × 部分不一致（四格中只有 $T=36$ 不同），属于转引偏差（同一论文内）。不裁决哪个值对。

### Q6 两篇论文中 FEDformer 在 Electricity 上的结果为什么不同？

- **数值**（MSE，按 $T=96, 192, 336, 720$）：
  - DLinear 表 2：0.193、0.201、0.214、0.246。转引自 FEDformer 论文（脚注），$L=96$。
  - PatchTST 表 3：0.186、0.197、0.213、0.233。PatchTST 作者用六个回看窗口 $L\in\{24,48,96,192,336,720\}$ 重跑，每个任务取最好的结果（第 535 行）。
- **条件**：$L$ 的选取方式不同（固定 96 对六选一），不明 → 不同；其余条件相同。
- **关系**：两份结果来源独立，但条件不同，属于不可比 × 不一致：差异不构成矛盾，两边都没有错。PatchTST 正是为了避免低估基线才重跑的（第 535 行）。
- **附带**：ETT 上两边 32 格中只有 ETTh1 $T=96$ 的 MSE 相同（0.376），属于"不可比 × 一致"，数值相同不说明什么。

### Q7 PatchTST 表 3 与附表 15 中的 FEDformer 为什么不同？

- **ETTh1 数值**（MSE / MAE）：

  | $T$ | 表 3 | 附表 15 |
  | --- | --- | --- |
  | 96 | 0.376 / 0.415 | 0.376 / 0.419 |
  | 192 | 0.423 / 0.446 | 0.420 / 0.448 |
  | 336 | 0.444 / 0.462 | 0.459 / 0.465 |
  | 720 | 0.469 / 0.492 | 0.506 / 0.507 |

- **来源**：
  - 表 3 是作者重跑的（第 535 行）。
  - 附表 15 的非 CI 基线转引自 DLinear 论文（表题，第 900 行），与 DLinear 表 3 的 FEDformer 逐格相同；而 DLinear 表 3 又转引自 FEDformer 论文。所以附表 15 的 FEDformer 是两跳转引，最终出处是 FEDformer 论文。FEDformer 论文目前只是桩节点，库中没有它的实验。
- **关系**：
  - 表 3 对附表 15：不可比（$L$ 的选取方式不同）× 部分不一致（$T=96$ 的 MSE 同为 0.376），不构成矛盾；
  - 附表 15 对 DLinear 表 3：同源 × 一致，算一份证据。DLinear 表 3 中 ETTh2 $T=720$ 的 MAE 印作 "0474"，PatchTST 印为 0.474，内容一致。

### Q8 单变量 ETTh1 上 PatchTST 与 DLinear

- **数值**（PatchTST 附表 8；DLinear 一列转引自 DLinear 论文，第 567 行）：

  | $T$ | PatchTST/42 MSE / MAE | DLinear MSE / MAE（附表 8） | DLinear MSE / MAE（DLinear 表 5） |
  | --- | --- | --- | --- |
  | 96 | 0.055 / 0.179 | 0.056 / 0.180 | 0.056 / 0.180 |
  | 192 | 0.071 / 0.205 | 0.071 / 0.204 | 0.071 / 0.204 |
  | 336 | 0.081 / 0.225 | 0.098 / 0.244 | 0.098 / 0.244 |
  | 720 | 0.087 / 0.232 | **0.189 / 0.359** | **0.119 / 0.274** |

- **关系**：DLinear 一列同源，除 $T=720$ 外一致；$T=720$ 是转引偏差。附表 8 与 DLinear 表 5 的其他基线中，只有 LogTrans $T=720$ 的 MAE 相差 0.001（0.629 对 0.628）。
- **比较**：$T=96$ PatchTST/42 略低；$T=192$ MSE 持平、MAE DLinear 低 0.001；$T=336$、$T=720$ PatchTST/42 更低（$T=720$ 无论取哪个 DLinear 值都如此，但差距大小取决于取哪个值，回答应说明）。
- **条件**：这是单变量设置，不能与表 3 的多变量结果混用（见 Q10）。

### Q9 PatchTST 表 4 中的基线是新跑的实验吗？

- PatchTST 表 4（自监督）中 DLinear、FEDformer、Autoformer、Informer 的来源原文未说明（`origin=unstated`）。
- 观测：四个基线共 96 格，与表 3 的对应值逐格相同。表 5、附表 12、附表 13 也是如此。
- **关系**：未知 × 一致。合理的推断是复用了表 3 的基线数值：DLinear 仍是转引 DLinear 论文，其余三个是作者在表 3 中的重跑。这是推断，应写明依据，不能当作原文陈述。
- **证据计数**：不增加新证据。

### Q10 DLinear 在 ETTh1、$T=96$ 上的 MSE 一处是 0.375、一处是 0.056，矛盾吗？

- 0.375 出自 PatchTST 表 3（多变量），0.056 出自 PatchTST 附表 8（单变量；DLinear 表 5 同值）。
- 多变量与单变量是不同的预测任务设置，属于不可比 × 不一致，不构成矛盾。
- **条件判断依据**：表题（附表 8 "Univariate"，表 3 "Multivariate"）与附录 A.3 第 567 行。

### Q11 两篇论文之间有没有同一方法在相同条件下的独立复现？

在当前库中没有。逐个方法的情况：

| 方法 | DLinear 论文 | PatchTST 论文 | 关系 |
| --- | --- | --- | --- |
| DLinear | 自己运行 | 转引 | 同源 |
| Pyraformer | 自己运行（$L=96$） | 转引 | 同源 |
| LogTrans | 转引 FEDformer 论文 | 转引 DLinear 论文 | 同源（两跳） |
| FEDformer、Autoformer、Informer | 转引 FEDformer 论文（$L=96$） | 表 3 重跑（六个 $L$ 取最好）；附表 15 转引 DLinear 论文 | 重跑一侧不可比；附表 15 一侧同源 |

所以"两篇论文的结果互相印证"的说法没有依据：一致的部分是同一份证据被转述，不一致的部分要么条件不同，要么是转引偏差。

### Q12 DLinear 表 6 中 Autoformer 去掉位置编码后在 Electricity 上的 MSE

- 表中印的是 0.193、0.201、0.214、0.246，与同表 FEDformer 的 wo/Pos. 行完全相同，也与表 2 中 FEDformer 在 Electricity 上的值相同。同表 Autoformer 在 Traffic 上的 wo/Pos. 行，则与表 2 中 Autoformer 的值相同（0.613、0.616、0.622、0.660）。
- 表 2 中 Autoformer 在 Electricity 上是 0.201、0.222、0.231、0.254。
- **关系**：同论文内来源未说明（未知）。观测提示这一行很可能抄成了 FEDformer 的数值；只标出疑点，不裁决，回答应说明原文无法确定 Autoformer 的真实值。
